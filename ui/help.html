v2RayTun Client (VLESS)

Runs Xray-core inside PyOrchestrator as a VLESS client. Paste a subscription URL or a raw vless:// link. The module opens local SOCKS5 and HTTP proxies (no TUN / no host VPN).

Setup

  1. Install the module from the catalog and open Settings.
  2. Paste the subscription or vless:// link.
  3. Optionally set SOCKS/HTTP ports and server index.
  4. Save settings and Start the module.
  5. Check Overview / Logs for health status.

Using the proxy from other containers

On the Docker network, point clients at pyorch-runtime:

  • HTTP_PROXY=http://pyorch-runtime:10809
  • HTTPS_PROXY=http://pyorch-runtime:10809
  • ALL_PROXY=socks5://pyorch-runtime:10808

Notes

  • Xray is downloaded once into data/bin/ (GitHub + mirrors).
  • Empty link field on save keeps the previous secret.
  • TUN mode is not supported inside the module sandbox.
